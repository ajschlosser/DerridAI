Language packs

Language models for Document Intelligence: spaCy for any language (with a multilingual fallback) and BookNLP for richer English analysis. Installing downloads the pack's pinned files from their published source and checks each SHA-256; corpus builds never download models.

Add a language pack

Paste a pack definition as JSON: pack_id, language (ISO 639 code), engine, label, source_url, license, and files with role (entity, coref or quote), filename, https url, sha256 and size. A pack for a language BookNLP itself does not support needs its own worker (DOCUMENT_NLP_BASE_URL_<LANG>).
