# 0.62.17 — Watertight Weasel

The blinding work in 0.62.16 filtered every corpus-build response for a record carrying a pending second opinion. That misses places where the first reviewer's answer is in a form the filter cannot see, or in a value derived from the record. This release audits those.

- **Record preview.** The preview builds a JSON-lines string from the record; the string is opaque to the filter. It is now built from the record as the current reviewer may see it.
- **Editorial memory.** The conventions and examples learned from confirmed answers included the first reviewer's answer for a field awaiting a second opinion. Those fields are now skipped for the reviewer who owes the opinion.
- **The rest of the record.** For a field awaiting a second opinion, the recorded rejections, re-check results, blind reveals and scheduled re-checks no longer repeat the first answer.
- **Ledger export.** The CSV no longer contains a value while it is held back: sealed model values on blind proposals and sealed first answers of re-checks show `[sealed]`. The decision rows (blind label, re-check, second label) still carry both answers.
- **A guard test.** Every `/api/pdf/corpus-builds` route must be listed in `tests/test_second_opinion_scrub.py` as either carrying records or build-level only, so a new route cannot be added without someone deciding whether it can leak.
- **Master's checks repaired.** The locale test failed on a missing `works.library_controls` string; seven frontend test files failed because `runtimeBridge` read the runtime when the module loaded, so any test that mocks part of the runtime broke on import (each export now reads it when called); and `mypy` rejected a `list[EvidenceItem]` passed to `evidence_sufficiency_issues`, which now accepts a sequence of mappings.

## What is not done

- Blinding is enforced by the response filter and the channels above. It does not cover a second reviewer reading the storage files directly or the ledger through a route other than the CSV export; the metrics endpoint reports rates, not values.
- No queue view for pending second opinions; second reviewers must be administrators.
