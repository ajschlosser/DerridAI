# 0.62.1 — Factory Reset

NUKE now does what a wiped `./data` directory does: the next load is a first-run setup. The previous reset only removed Chroma collections and the current browser workspace, so accounts, PDF corpora, provider profiles, and job history survived.

- **Accounts:** users, sessions, login lockouts, and custom roles are deleted. Builtin admin/researcher roles and default researcher permissions are restored. The session cookie is cleared, and `/api/auth/status` reports `bootstrap_required`.
- **System store:** provider profiles, annotations, language edits, researcher text policies, and the jobs table are cleared. English and Québec French dictionaries are re-seeded.
- **Corpora:** PDF assets, builds, and publications under `.home/pdf-corpus` are removed, along with backup/restore temp directories. Corpus Builder in-memory cancel/runtime maps are dropped.
- **Chroma:** collections are deleted and the persistence directory is emptied (including `chroma.sqlite3`), except `.gitkeep`.
- **Browser:** after a successful nuke the UI deletes DerridAI IndexedDB databases (including researcher-scoped ones) and `localStorage` keys, then reloads.
- **Left alone:** downloaded models under `data/models` and Compose Ollama files under `data/ollama`.
- **UI:** Settings copy and the confirmation dialog describe a fresh-install reset, in en-US and fr-CA.
