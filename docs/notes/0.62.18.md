# 0.62.18 — Hands-free Heron

- **Hands-free mode.** A build can now settle itself with no one reviewing it. Turn it on under step 5 of the build setup, or run it later from Bulk actions → "Run hands-free…". You set:
  - how many extra enrichment passes to run first (0–3, so later passes can use what earlier ones found);
  - the model confidence at which a proposal is taken (50–99%);
  - what to do with a field that is still unsure: take the model's best guess, or leave it for you;
  - whether to accept records with nothing left waiting, and whether to publish when every record is accepted (off by default).
    Nothing it does is presented as a person's decision: a value it takes stays "LLM inferred" (method `autonomous_policy`, with a reason saying no person reviewed it), and an accepted record says `accepted_by: autonomous`. Anything it cannot settle (a source-text problem, a field with no proposal, an unusable value, a record a person already touched) is left, and a report on the build lists each record with the reason. The rules live in one small module (`api/app/autonomous.py`), which is where smarter algorithms can go later.
- **A quoted speaker can be added.** Optional details a record simply did not have (quoted speaker, quoted author, topics…) had no value and no status, so they were never listed and there was nowhere to add one. The Metadata tab now ends with "Add more details", listing them empty.
- **Save & mark reviewed no longer gets covered.** While you edit record text, the decision bar is replaced by an edit bar (Cancel, Save & mark reviewed) that is always in view; saving does not accept the record or move on.
- **The review screen is more compact.** Headings that repeated what the queue shows are gone or one line, the text card's actions stay on one line, and on a window under 860 pixels high the metadata help paragraph and the decision bar's heading give way to the record. Whether the queue is hidden is now remembered. At 1366×768 the record text shows about twelve lines instead of five.
- **The default model is not loaded unasked.** The app used to warm the default provider profile's model every time it opened, which loads it into memory and evicts whichever model is in use. That is now off; turn it on in LLM Providers ("Load the default model when the app opens").

## What is not done

- Hands-free mode is a policy, not a smarter reviewer: it takes or leaves proposals by confidence and does not check them against each other beyond what the enrichment passes already do.
- The "fit in one screen" work is compaction, judged from the mock API at common sizes. I could not see your real build, so if something still needs scrolling, tell me which screen.
- The hands-free dialog and setup were checked in the browser against the mock API, not on a real build.
