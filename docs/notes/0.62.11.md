# 0.62.11 — Measured Marmot

Measurement groundwork for enrichment experiments. Built on 0.62.10.

- **Ledger.** Every model proposal (value, stated confidence, whether it cited a real source block) and every model call (duration, success) is appended to `enrichment_ledger.jsonl` alongside autofills and review decisions.
- **Run ids.** Each enrichment pass tags its events with its operation id; a build's first enrichment uses `build-<id>`.
- **Concurrency limit.** `ENRICHMENT_MAX_CONCURRENT_RUNS` (default 1) caps enrichment runs across all builds; an extra run is refused with a message.
- **Ten measures** at `GET /api/pdf/corpus-enrichment-metrics?build_id=&run_id=`: acceptance, calibration (Brier and reliability), correction and clearing rates, precision against coverage, inter-model agreement, stability across runs, share still needing a person, source grounding, time per call and per kept value, and the learning curve with unresolved fields. A measure with no data says so.
- **Panel** "How well is enrichment working?" in the Corpus Builder, loaded on request, in English and French.

## What is not done

- Reviewer time, tokens and money, error severity, and the experiment layers (slices, intervals, arms, baselines, gold set, reproducibility metadata, export) are planned in `feature/metrics`.
- Existing builds have no ledger history.
- The panel was not checked in a browser; no live-model run.
