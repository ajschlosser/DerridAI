# 0.62.4 — Whimsical Wombat

The Home page's Background operations panel is now a Vue component instead of an HTML string, and the accessibility problems around it are fixed. The floating operations dock, toasts and job details dialog still belong to the runtime and behave as before.

- **Focus no longer gets lost.** The old panel was torn down and rebuilt on every poll, so keyboard focus could drop to the page while a job ran. Rows are now keyed and updated in place, and if the focused button disappears (for example Cancel when a job finishes) focus moves to another control in the same row.
- **Structure for assistive technology.** One level-2 heading, section headings, real lists, a named `progressbar` for each running operation, buttons named after their row ("Cancel PDF corpus build") that still contain their visible text, status shown as icon plus text, and one polite announcement when an operation completes, fails, or is cancelled. Progress ticks are never announced.
- **Easier to read.** Work is grouped into Needs attention, In progress, and History (by day, with a Show all control), with filter chips that show counts. Failures show what went wrong on the row. Running jobs show an estimated time remaining only when the rate is steady (never for PDF corpus builds, whose progress blends several stages). Durations and times use `Intl` in the interface language.
- **Undo instead of confirm.** Remove and Clear finished hide the rows at once and offer Undo for a few seconds before anything is deleted; leaving the page commits a pending removal. Clear finished never touches running work.
- **Motion and modes.** A progress sheen, a check that draws on completion, and a floating empty-state icon, all off under reduced motion; pressed filter chips and status icons stay legible in forced-colors (high-contrast) mode.
- **Translated.** New strings and the formerly hard-coded job labels, fact names, sentence fragments, and "N of M" progress have English and French keys. Text written by the server (stage details, error messages, a job's own label such as "Languages · fr-CA") is unchanged and still English.
- **Contrast and target size.** The filter chip count behind a pressed chip, the carousel dots (now 24 px targets drawing a dot at 3:1), the sidebar collapse arrow (24 px, full opacity), the sign-in subtitle, the More tools heading, the Ctrl K hint, and three dashboard helper-text colours now meet WCAG 2.2 AA. The header and sign-in language selects and the dashboard search-scope select have accessible names.
- **Dock.** The dock no longer says "Operations" twice when there is nothing more specific to show.
- **Tests without exports.** `tests/conftest.py` supplies throwaway storage, and CONTRIBUTING no longer asks people to export `CHROMA_DATA_ROOT`, `AUTH_DB_PATH`, `SYSTEM_DB_PATH` or `CHROMA_PATH`. `docker-compose.yml` reads the same names, and an exported test path made a running API container crash-loop.

## Validation

Linux, Python 3.12, Node 22, on the branch after merging `master` at 0.62.3:

- Vitest: 143 passed. Playwright with axe (WCAG 2.0 to 2.2, A and AA): 80 passed, including 30 for the panel across eight Storybook states, ARIA-tree checks, reflow at 320 px, 200% text, text spacing, 24 px targets, and reduced motion.
- `npm run lint`, `typecheck`, the production build, and the Storybook build passed. `ruff`, `mypy`, and `compileall` passed. pytest passed except the release-notes check, which needed this file; it was not re-run after adding it.
- Measured on a production Docker build of the branch (before merging `master`): axe reported 0 violations on the panel, the whole Home page, and the sign-in screen. Items axe marks "needs review" were measured by hand. The Docker images were not rebuilt after the merge.
- Not done: testing with a real screen reader (NVDA, JAWS, VoiceOver), which needs a person. The ARIA-tree tests show what assistive technology is given but are not a substitute.
- The panel was exercised with a mix of running, queued, failed and finished jobs supplied by an intercepted `/api/jobs`, not with real long-running work.
