# 0.53.0 — Manic Monkey

- Makes background refresh **merge-only** with respect to active human work. Dirty reviewed-text and advanced-metadata drafts remain pinned to their record and are not replaced by polling, queue growth, or later worker completion. Record selection changes only through explicit reviewer navigation.
- Adds exact **Preview JSONL** for every record, generated by the same backend serializer used at publication. The preview exposes validation errors and unresolved fields and supports copy/download without inventing a second frontend serialization path.
- Adds conservative **LLM Touch-up** in normal Record Review and Focus View. The model may repair punctuation, formatting, line wrapping, obvious OCR artefacts, and clear extraction errata, but is instructed not to paraphrase, summarize, translate, reorder, or normalize deliberate stylistic/typographic features. The proposal is applied only to the local reviewed-text draft; immutable extracted source is preserved.
- Strengthens default pre-enrichment **Clean text** across all records: repeated boundary titles/headers/footers/page numbers, redundant empty lines, line-break hyphenation, zero-width/soft-hyphen/ligature OCR artefacts, repository boilerplate, and artificial prose line wraps are cleaned conservatively while likely poetry, quotations, lists, headings, footnotes, and deliberate lineation are protected.
- Keeps deterministic region/primary-text rules as fast structural defaults but now asks the discourse LLM to **corroborate** them. Agreement strengthens the proposal; disagreement becomes an explicit review item instead of silently replacing either source of evidence.
- Ensures valid LLM proposals, including **discourse role**, are prefilled for review regardless of raw model confidence. Confidence changes review emphasis, not whether the reviewer must re-select the model's own proposed value.
- Adds empirical **confidence calibration** from human accept/correct decisions and model/profile effectiveness summaries so raw LLM confidence can be compared with observed reviewer acceptance by field and confidence band.
- Makes build-local **Editorial Memory** inspectable and resettable. Only human-confirmed/overridden decisions become reusable conventions/examples; they remain advisory prompt context, never source evidence or automatic truth.
- Fixes mid-pipeline provider switching so newly scheduled tasks actually resolve and use the latest selected profile while already-running requests finish with their original provider/model. Per-task/model effectiveness provenance remains auditable.
- Reworks Finish Corpus semantics: rejected records are excluded from required-metadata/publication checks; mixed accepted/rejected builds can publish the accepted corpus; an all-rejected build becomes an explicit **No publishable records** state with Return to review, Restore rejected, and Start another build actions. Blockers provide direct **Go fix** routes.
- Keeps Focus View's breadcrumb/history navigation plus Previous/Next queue navigation and exposes Clean Text, LLM Touch-up, JSONL Preview, metadata review, source evidence, and revision history through the same shared components as normal review.
- Extends Storybook with JSONL Preview, LLM Touch-up, Editorial Memory, automation-effectiveness/calibration, publication-terminal states, and Québec French stress stories while continuing the shared dialog/field/review component migration.
- Preserves first-class English and **Québec French (`fr-CA`)** localization and WCAG 2.0 AA-oriented keyboard/focus/dialog/status behavior.
- Consolidates redundant release-identity assertions from older hotfix tests while retaining durable feature/regression coverage.
