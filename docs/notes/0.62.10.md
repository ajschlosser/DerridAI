# 0.62.10 — Careful Crane

Sentence-safe records, one main-text start page, first-page inference and LLM autofill. Built on 0.62.9.

- **Records stay on sentence ends.** After segmentation, every record boundary is checked: the block before it must end a sentence (or be a heading or caption) and the block after must not continue one. A boundary that fails moves to the nearest clean one, or is dropped so the records join. A sentence longer than three times the profile's soft maximum is kept whole and reported (`sentence_boundary_report` on the build) instead of being cut. This cannot be an absolute guarantee: verse, lists and OCR noise have no sentence ends, and an abbreviation such as "Dr." looks like one.
- **Removed** the `review_manifest_before_segmentation` mode. The UI never enabled it.
- **A record that straddles the main-text start page is flagged.** Choose main text, front matter, or split it. A region you chose yourself is never flagged.
- **One main-text start page.** Editing it on the document manifest now writes through to the confirmed layout plan, and records the layout had labelled are relabelled from the new page. This was the cause of 18 versus 53. Printed page numbers are left as they were.
- **First main-text page is suggested at load.** Clues: a first-chapter bookmark, a "Chapter One" heading (contents listings skipped), Roman numerals giving way to page 1, and the end of front matter. An "Introduction" is never a start marker. A value is offered only at 90% confidence or more, with its clues shown in Edit document metadata.
- **LLM autofill.** Blended confidence = (accepted + 20 × the model's report) ÷ (reviews + 20), per model and field. At 90% or more, with a cited source block, the value is filled in as "LLM inferred" even if the model asked for review. Autofill is suspended for a model and field below 80% precision after 20 reviews. About 10% of autofilled values carry a "Spot check" badge. A value a person changes or clears is remembered and shown to later passes. Every proposal and decision is appended to `enrichment_ledger.jsonl`, tagged with run, model and field.

## What is not done

- The 90% start-page threshold is unmeasured: no confirmed layouts were available here. Run `scripts/evaluate_main_text_start.py <corpus_root>` before trusting it.
- Editing the layout plan does not update the manifests of existing builds.
- The metrics view, per-run ids on events and the concurrency limit are not built.
- No impact preview when the start page changes.
