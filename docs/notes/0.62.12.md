# 0.62.12 — Rigorous Robin

Groundwork for enrichment experiments. Built on 0.62.11.

- **Conditions on every event:** arm, ablations, gold flag, model version, prompt version, code version, temperature and seed.
- **Ablations are real switches:** a request may turn off `autofill` (the no-autofill baseline), `blended_confidence`, `rejection_memory`, `reviewer_conventions` or `cross_build_learning`.
- **Randomized arms:** records are assigned to arms by hash, so assignment is unbiased, repeatable and needs no stored table.
- **Frozen gold set:** a fixed 5% hash sample of records, scored but never used for learning or the blended confidence.
- **More measures:** correction severity (cosmetic, near-miss, substantive, cleared), repeats of rejected values, text support for name fields, outcomes where models disagreed, review time between decisions, time to first useful value, and autofill suspensions.
- **Intervals:** 95% Wilson intervals on acceptance, substantive error, autofill precision, grounding and precision at each threshold.
- **Slices and export:** filter by build, run and arm, group by any event column, and download every event as CSV (`/api/pdf/corpus-enrichment-ledger.csv`).
- **Blind review and anchoring:** with `experiment.blind_rate` set, that share of records shows the reviewer an empty field; the model's value is sealed in the ledger, the reviewer's own value is scored against it, and the suggestion is revealed after saving. Comparing agreement when blind with acceptance when shown gives an anchoring estimate. Blind fields are never autofilled.
- **Experiment block** on build and enrichment requests: `ablations`, `arms`, `arm_salt`, `blind_rate`, `model_version`.
- Helpers not yet applied to any figure: bootstrap intervals, McNemar's test, Cohen's kappa.

## What is not done

- Tokens and money (providers report no usage), inter-annotator agreement, reviewer self-consistency, power planning, exact model hashes, held-out-corpus generalization.
- Review time is an upper-bound estimate from gaps between decisions. Text support checks the whole record text, not the cited block.
- No browser check of the panel; no live-model run.
