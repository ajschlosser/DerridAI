# 0.51.0 — Krazy Kangaroo

- Rebuilt **Edit document metadata** on the shared `UiDialog` foundation with an opaque surface, focus trap/restoration, Escape dismissal, stable internal scrolling, responsive sizing, and a sticky save area.
- Reworked `DocumentManifestEditor` into schema-driven, two-column bibliographic sections with clearer grouping, propagation impact, changed-field counts, and explicit confirmation that record-level overrides are preserved.

- Added the missing close icon to the shared icon system and removed obsolete CSS left behind by replaced review components.
- Preserved durable record-text drafts, collaborative field ownership, hot-swappable enrichment profiles, Editorial Memory, deterministic constraints, and reversible text cleanup from 0.50.x.
- Added English and Québec French copy for all new document-metadata and automation-effectiveness states.
- Continued WCAG 2.0 AA hardening with semantic dialog labelling, keyboard focus containment/restoration, visible focus rings, responsive controls, readable type, and reduced-motion-safe behavior.
