# API and Integration Contract Requirements

**Scope:** REST, GraphQL, WebSocket/realtime transport, typed frontend clients, authorization, pagination/bounds, errors, schema/code generation, and transport compatibility.  
**Parent requirements:** [Global requirements](GLOBAL_REQUIREMENTS.md)

## Transport responsibilities

| ID | Requirement | Acceptance criteria | Parent | Implementation trace | Verification |
| --- | --- | --- | --- | --- | --- |
| **PRD-API-001** | REST MUST remain the command/mutation transport for uploads, review decisions, claim validation, job creation/cancellation, schema/provider/user administration, publication, backup/restore, and other state-changing operations unless explicitly superseded by a documented command transport. | State-changing product operations are not introduced as hidden GraphQL query side effects or realtime messages. | PRD-G-035, PRD-G-039 | [Architecture](../ARCHITECTURE.md) | **Direct/Partial:** [frontend API contract](../../tests/test_frontend_api_contract.py); route-specific backend tests |
| **PRD-API-002** | GraphQL MUST remain a read-only cELF-aware query façade over shared transport-independent read services. | GraphQL has no mutations/subscriptions; reads share authorization, owner scoping, blind-review scrubbing, and data semantics with REST. | PRD-G-018, PRD-G-035, PRD-G-040 | [GraphQL](../GRAPHQL.md); [Architecture](../ARCHITECTURE.md) | **Direct:** [GraphQL façade](../../tests/test_graphql_facade.py); [GraphQL Document Intelligence](../../tests/test_graphql_document_intelligence.py) |
| **PRD-API-003** | WebSocket realtime transport MUST carry notifications/live hints rather than becoming an independent mutation or authoritative-data API. | Realtime messages can tell clients what changed/what is happening; durable state is fetched/resynchronized through canonical REST/GraphQL reads. | PRD-G-003, PRD-G-035 | [Realtime](../REALTIME.md); [Architecture](../ARCHITECTURE.md) | **Direct:** [realtime plane](../../tests/test_realtime_plane.py) |
| **PRD-API-004** | REST and GraphQL representations of the same cELF read MUST derive from shared read-service semantics rather than independently reimplementing authority/provenance logic. | Equivalent reads agree on identity/provenance/authorization; a transport change does not change scholarly meaning. | PRD-G-040 | [GraphQL](../GRAPHQL.md) | **Direct:** [GraphQL façade](../../tests/test_graphql_facade.py); [GraphQL Document Intelligence](../../tests/test_graphql_document_intelligence.py) |

## API contract requirements

| ID | Requirement | Acceptance criteria | Parent | Implementation trace | Verification |
| --- | --- | --- | --- | --- | --- |
| **PRD-API-005** | Typed frontend REST calls MUST correspond to real FastAPI methods/routes. | CI fails when a checked-in frontend request references a missing or method-incompatible OpenAPI route. | PRD-G-036, PRD-G-039 | API contract | **Direct:** [frontend API contract](../../tests/test_frontend_api_contract.py) |
| **PRD-API-006** | Checked-in frontend GraphQL operations MUST validate against the live GraphQL schema. | Unknown fields/arguments/types or accidental mutations fail contract validation before merge. | PRD-G-036, PRD-G-039 | [GraphQL](../GRAPHQL.md) | **Direct:** [frontend GraphQL contract](../../tests/test_frontend_graphql_contract.py) |
| **PRD-API-007** | The checked-in GraphQL SDL artifact MUST match the live Strawberry schema. | Schema drift fails CI with instructions to regenerate; `--check` does not rewrite files. | PRD-G-014, PRD-G-036 | [GraphQL](../GRAPHQL.md) | **Direct:** [GraphQL schema artifact](../../tests/test_graphql_schema_artifact.py) |
| **PRD-API-008** | GraphQL public errors MUST use stable machine-readable codes for supported error classes. | Forbidden, not found, bad request, unavailable, and related public errors expose stable `extensions.code` independent of localized/human-readable message wording. | PRD-G-025, PRD-G-039 | [GraphQL](../GRAPHQL.md) | **Direct/Partial:** [GraphQL façade](../../tests/test_graphql_facade.py); GraphQL error tests |
| **PRD-API-009** | Public API list/query endpoints MUST be bounded through pagination, explicit limits, or other documented caps. | Clients cannot request unbounded corpus/vector/claim documents through one read; server validates caps and defaults. | PRD-G-033 | [GraphQL](../GRAPHQL.md) | **Direct/Partial:** [GraphQL façade](../../tests/test_graphql_facade.py); [GraphQL record reads](../../tests/test_graphql_record_reads.py) |
| **PRD-API-010** | GraphQL production behavior MUST prevent unsupported query capabilities that weaken the intended bounded read façade. | Unsupported GET-query execution, mutations, subscriptions, and production introspection are rejected according to the documented contract. | PRD-G-018, PRD-G-033 | [GraphQL](../GRAPHQL.md) | **Direct:** [GraphQL façade](../../tests/test_graphql_facade.py) |
| **PRD-API-011** | API authorization MUST be applied before returning sensitive Record, memory, provider, system, or reviewer data. | Admin/capability/owner/blind-review policies cannot be bypassed by selecting a different transport or nested query shape. | PRD-G-018 | [GraphQL](../GRAPHQL.md); [Architecture](../ARCHITECTURE.md) | **Direct:** [GraphQL façade](../../tests/test_graphql_facade.py); [researcher route policy](../../tests/test_researcher_route_policy.py); [second-opinion scrub](../../tests/test_second_opinion_scrub.py) |
| **PRD-API-012** | API validation MUST reject invalid domain identifiers/configuration before invoking expensive or destructive downstream work where feasible. | Invalid collection names, malformed schema imports, unsupported capture options, and invalid pipeline graphs fail at validation/service boundaries. | PRD-G-011, PRD-G-033 | typed request/service contracts | **Direct:** [collection-name schema](../../tests/test_collection_name_schema.py); [metadata schema](../../tests/test_metadata_schema.py); [corpus capture routes](../../tests/test_corpus_capture_routes.py); [pipeline contracts](../../tests/test_pipeline_contracts.py) |
| **PRD-API-013** | API responses MUST not expose secret fields merely because internal storage objects contain them. | Public provider/connection/job/config projections redact or omit credentials and secret-bearing internal settings. | PRD-G-018, PRD-NFR-003 | security/API contract | **Direct/Partial:** [Chroma connection](../../tests/test_chroma_connection.py); [editorial memory/provider switch](../../tests/test_editorial_memory_and_provider_switch.py); route-policy tests |
| **PRD-API-014** | Read APIs that expose source text or Record-derived values MUST apply applicable researcher text/content and blind-review policies consistently. | REST and GraphQL cannot return text/value content that another protected route would scrub for the same caller. | PRD-G-018 | shared read-service contract | **Direct:** [GraphQL record reads](../../tests/test_graphql_record_reads.py); [second-opinion scrub](../../tests/test_second_opinion_scrub.py); [GraphQL façade](../../tests/test_graphql_facade.py) |
| **PRD-API-015** | API compatibility changes SHOULD be additive/version-compatible where scholarly correctness is not at risk. | Existing typed clients continue to work or receive an explicit migration/deprecation path; incorrect legacy behavior may be rejected when required for integrity. | PRD-G-039 | [Architecture](../ARCHITECTURE.md) | **Contract:** [frontend API contract](../../tests/test_frontend_api_contract.py); [frontend GraphQL contract](../../tests/test_frontend_graphql_contract.py) |
