# Metadata Schema, FieldAssertion, and Human Review Requirements

**Scope:** Metadata schema definition, stable field identity, assertion semantics, evidence/assessment, human review, ownership, confirmed absence, audit history, and review workflows.  
**Parent requirements:** [Global requirements](GLOBAL_REQUIREMENTS.md)
