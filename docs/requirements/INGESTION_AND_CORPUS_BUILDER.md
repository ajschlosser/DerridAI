# Source Acquisition, Ingestion, and Corpus Builder Requirements

**Scope:** Corpus Capture, direct source ingestion, extraction, structure/transcription, segmentation, Record creation, source locations, revision, review, and publication readiness.  
**Parent requirements:** [Global requirements](GLOBAL_REQUIREMENTS.md)
