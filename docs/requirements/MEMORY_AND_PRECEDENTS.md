# Metadata Memory, Claim Memory, and Response Memory Requirements

**Scope:** Metadata exemplars/precedents, editorial memory, claim memory, response memory, projection indexes, eligibility, owner scope, evidence status, rebuild behavior, and provenance.  
**Parent requirements:** [Global requirements](GLOBAL_REQUIREMENTS.md)

## Shared memory requirements

| ID | Requirement | Acceptance criteria | Parent | Implementation trace | Verification |
| --- | --- | --- | --- | --- | --- |
| **PRD-MEM-001** | Research and metadata memory MUST remain advisory derived state rather than a new source of scholarly authority. | A memory hit can guide a proposal or generation but does not itself make a field/claim authoritative. | PRD-G-003, PRD-G-016 | [Metadata Memory](../METADATA_MEMORY.md); [cELF](../../SPECIFICATION.md) | **Direct/Partial:** [research memory](../../tests/test_research_memory.py); [claim memory](../../tests/test_claim_memory.py); [memory prefill](../../tests/test_memory_prefill.py) |
| **PRD-MEM-002** | Memory projections MUST rejoin authoritative rows before consequential use where the authoritative row contains eligibility/authority state. | Deleted, superseded, downgraded, or otherwise ineligible authoritative entries cannot remain eligible solely because a vector projection is stale. | PRD-G-003, PRD-G-016 | [Metadata Memory](../METADATA_MEMORY.md) | **Direct:** [research memory](../../tests/test_research_memory.py); [metadata memory inspector](../../tests/test_metadata_memory_inspector.py) |
| **PRD-MEM-003** | Memory retrieval MUST expose fallback/degraded behavior rather than silently disappearing when semantic infrastructure is unavailable. | Semantic unavailability may fall back to lexical matching where configured and records the fallback reason/mode. | PRD-G-025, PRD-G-033 | [PR #277](https://github.com/ajschlosser/DerridAI/pull/277) | **Direct:** [research memory](../../tests/test_research_memory.py); [progressive metadata retrieval](../../tests/test_progressive_metadata_retrieval.py) |
| **PRD-MEM-004** | Memory retrieval behavior MUST be pipeline-defined while authority/eligibility constraints remain non-tunable invariants. | Candidate depth, similarity threshold, lexical fallback, and top-K may be configured; reviewer validation, owner scope, support/evidence requirements cannot be disabled by a memory pipeline. | PRD-G-010, PRD-G-016 | [PR #277](https://github.com/ajschlosser/DerridAI/pull/277) | **Direct:** [memory pipeline](../../tests/test_memory_pipeline.py); [pipeline manager](../../tests/test_pipeline_manager.py) |
| **PRD-MEM-005** | Memory reads MUST be scoped to the authorized owner/user where stored material is private. | A user's response/claim memory is not returned to another user unless an explicit product rule grants access. | PRD-G-018 | security/memory contract | **Direct:** [unified memory/provenance](../../tests/test_unified_memory_provenance.py) (`test_research_memory_reads_are_owner_scoped`); [claim memory](../../tests/test_claim_memory.py) |
| **PRD-MEM-006** | Projection/index failure MUST NOT make an already-saved canonical review decision appear unsaved. | Canonical reviewer decision persistence and derived-memory update status are reported independently. | PRD-G-003, PRD-G-025 | review/memory contract | **Direct:** [metadata batch decisions](../../tests/test_metadata_batch_decisions.py) |

## Metadata memory requirements

| ID | Requirement | Acceptance criteria | Parent | Implementation trace | Verification |
| --- | --- | --- | --- | --- | --- |
| **PRD-MEM-007** | Metadata exemplars MUST originate from eligible reviewed FieldAssertions with resolvable evidence/provenance. | Unreviewed model guesses and unsupported values are not projected as trusted exemplars. | PRD-G-005, PRD-G-012, PRD-G-016 | [Metadata Memory](../METADATA_MEMORY.md) | **Direct:** [metadata exemplar projection](../../tests/test_metadata_exemplar_projection.py); [progressive metadata exemplars](../../tests/test_progressive_metadata_exemplars.py) |
| **PRD-MEM-008** | Stable field identity SHOULD be used to match precedents across compatible schema revisions/renames. | A field rename that preserves semantic identity does not orphan compatible precedent memory. | PRD-G-007, PRD-G-016, PRD-G-039 | [Metadata Memory](../METADATA_MEMORY.md) | **Partial:** [unified memory/provenance](../../tests/test_unified_memory_provenance.py); [metadata schema](../../tests/test_metadata_schema.py) |
| **PRD-MEM-009** | Confirmed absence MAY be used as advisory precedent only when its evidence/authority contract is satisfied. | Confirmed absence is rendered/retrieved as absence, not a positive value, and does not become automatic truth for the new Record. | PRD-G-004, PRD-G-016 | [Metadata Memory](../METADATA_MEMORY.md) | **Direct:** [memory prefill](../../tests/test_memory_prefill.py); [progressive metadata exemplars](../../tests/test_progressive_metadata_exemplars.py) |
| **PRD-MEM-010** | Metadata-precedent retrieval MUST record which exemplar IDs were supplied to a model/run. | Later audit can distinguish retrieved precedent from the model's new proposal and identify the examples used. | PRD-G-002, PRD-G-014 | [Metadata Memory](../METADATA_MEMORY.md); [PR #278](https://github.com/ajschlosser/DerridAI/pull/278) | **Direct/Partial:** [metadata-precedent pipeline](../../tests/test_metadata_precedent_pipeline.py); [progressive metadata exemplars](../../tests/test_progressive_metadata_exemplars.py) |
| **PRD-MEM-011** | Metadata Memory inspection MUST hide superseded/ineligible entries from default trusted views while preserving appropriate auditability. | Inspector resolves evidence-bound current entries and does not present superseded reviewer memory as current precedent. | PRD-G-016, PRD-G-039 | [Metadata Memory](../METADATA_MEMORY.md) | **Direct:** [metadata memory inspector](../../tests/test_metadata_memory_inspector.py) |
| **PRD-MEM-012** | System Data metadata examples MUST expose useful scholarly provenance without exposing vector-internal details as authority. | Inspector can filter by field/schema/source/record/evidence metadata; raw vector implementation details are not required to understand exemplar provenance. | PRD-G-031, PRD-G-037 | System Data contract | **Direct:** [system metadata exemplars](../../tests/test_system_metadata_exemplars.py) |

## Claim and response memory requirements

| ID | Requirement | Acceptance criteria | Parent | Implementation trace | Verification |
| --- | --- | --- | --- | --- | --- |
| **PRD-MEM-013** | Claim memory MUST include only claims that satisfy the configured human-validation/support eligibility contract. | An unvalidated claim cannot become trusted claim memory merely because it has a vector embedding. | PRD-G-013, PRD-G-016 | claim-memory contract | **Direct:** [claim memory](../../tests/test_claim_memory.py); [research memory](../../tests/test_research_memory.py) |
| **PRD-MEM-014** | Claim memory MUST preserve support-binding provenance needed to determine whether cited Records are available in the current evidence packet. | Prior validated claims may steer synthesis, but the generator is told which prior support is current evidence and cannot cite unavailable evidence as though it were supplied now. | PRD-G-013, PRD-G-016 | [PR #277](https://github.com/ajschlosser/DerridAI/pull/277) | **Direct:** [research memory](../../tests/test_research_memory.py); [unified memory/provenance](../../tests/test_unified_memory_provenance.py) |
| **PRD-MEM-015** | Response memory MUST apply configured quality/eligibility rules before a prior response can steer a new response. | Ungraded or below-threshold responses do not steer when the active memory contract requires an eligible grade/status. | PRD-G-016, PRD-G-034 | research-memory contract | **Direct:** [research memory](../../tests/test_research_memory.py) |
| **PRD-MEM-016** | Response/claim memory MUST be optional per Research run. | A run can disable prior response/claim memory and benchmarks can force memory off for controlled comparison. | PRD-G-014, PRD-G-016 | [PR #286](https://github.com/ajschlosser/DerridAI/pull/286) | **Direct:** [pipeline benchmark](../../tests/test_pipeline_benchmark.py); [pipeline tracing](../../tests/test_pipeline_tracing.py) |
